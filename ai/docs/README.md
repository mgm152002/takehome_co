# AI-Assisted Engineering Record

This directory documents how the Vehicle Auction Search MVP was designed, implemented, reviewed, and prepared for deployment with AI assistance.


## Documents

| Document | Purpose |
|---|---|
| [Technical design](design.md) | Product constraints, system architecture, data model, ranking strategy, reliability, and tradeoffs |
| [Work items and delivery record](work-items.md) | Planned scope, completed increments, decisions, and verification evidence |
| [Append-only delivery log](progress-log.md) | Chronological assumptions, decisions, progress, evidence, blockers, and resolutions |
| [Prompts and responses](prompts-and-responses.md) | User requests preserved in substance with concise implementation outcomes |

## Working model

1. Define the outcome, constraints, and acceptance criteria.
2. Record an implementation-ready design before changing the system.
3. Break delivery into bounded work items with clear outputs.
4. Implement on a feature branch and verify each increment.
5. Capture material decisions, tradeoffs, and production follow-ups.
6. Promote reviewed work to `main` and maintain deployment documentation.
